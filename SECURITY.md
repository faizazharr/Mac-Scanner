# Security & Privacy Policy 🔒

## 🛡️ Absolute Privacy & Zero-Data Collection Guarantee

**The developer and all open-source contributors DO NOT COLLECT, HARVEST, OR STORE ANY PRIVATE INFORMATION** from users who install or contribute to MacScanner.

- **100% On-Device Local Processing**: All disk analysis, leftover calculations, CPU/RAM telemetry, and hardware diagnostic tests execute purely in local memory on your Mac.
- **Zero Telemetry & No Remote Servers**: MacScanner does not connect to any external cloud backend, contains zero tracking SDKs, and never uploads your personal data or serial numbers to the internet.
- **Non-Destructive Operations**: All delete actions strictly use native macOS `FileManager.trashItem` so files can always be restored from the Trash.

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or safety issue in MacScanner, please report it responsibly by opening a GitHub Security Advisory or contacting the maintainer directly at `faizazharr@gmail.com`.
