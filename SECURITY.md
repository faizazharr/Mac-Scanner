# Security & Privacy Policy 🔒

## 🛡️ Jaminan Privasi Mutlak (Privacy & Zero-Data Collection Guarantee)

### 🇮🇩 Bahasa Indonesia:
**Pengembang dan seluruh kontributor proyek MacScanner TIDAK MENGAMBIL, MEREKAM, ATAU MENYIMPAN INFORMASI PRIVASI APAPUN** dari siapapun yang menginstal atau berkontribusi pada aplikasi ini.

- **100% Eksekusi Lokal (*On-Device*)**: Seluruh pemindaian disk, penghitungan ukuran direktori, deteksi telemetri CPU/RAM, dan pengetesan hardware berjalan murni di memori Mac pengguna.
- **Tanpa Panggilan Jaringan (*No Remote Phone-Home*)**: MacScanner tidak memiliki server eksternal, tidak menggunakan SDK pelacak/analitik pihak ketiga, dan tidak pernah mengunggah data atau serial number Mac Anda ke internet.
- **Operasi Non-Destruktif**: Seluruh aksi penghapusan file menggunakan `FileManager.trashItem` resmi macOS (dapat dikembalikan dari Trash).

---

### 🇬🇧 English:
**The developer and all open-source contributors DO NOT COLLECT, HARVEST, OR STORE ANY PRIVATE INFORMATION** from users who install or contribute to MacScanner.

- **100% Local Processing**: All operations run locally via native Mach/Darwin kernel APIs.
- **Zero Telemetry & No Remote Analytics**: No network telemetry, no tracking pixels, and no remote servers.
- **Non-Destructive Operations**: Reversible trash staging via native Apple APIs.

---

## 🚨 Pelaporan Keamanan (Reporting a Vulnerability)

Jika Anda menemukan celah keamanan atau bug pada MacScanner, silakan laporkan secara bertanggung jawab melalui GitHub Security Advisory atau email langsung ke `faizazharr@gmail.com`.
